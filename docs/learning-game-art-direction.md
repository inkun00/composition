## 이미지와 동작 적용

- 기억의 관측소는 `/learning-art/observatory.webp`와 투명 안내 새 `/learning-art/guide-bird.webp`를 사용한다. 장식용 별자리 SVG는 제거했다. 진행 별, 확인 표시, 실제 음악 기호는 의미를 전달하는 UI로 유지한다.
- 카드는 앞뒷면을 분리한 원근 뒤집기와 짧은 착지 동작을 사용한다. 성공은 밝아지는 진행 별·점수 배지·확인 표시로, 오답은 작은 흔들림·테두리·설명 문장으로 구분한다.
- 동작 줄이기 설정에서는 뒤집기 전환과 보상·오답 애니메이션을 끈다. 버튼의 키보드 동작, 숨겨진 카드의 접근성 이름, 결과 제목의 초점 이동, 상태 안내는 유지한다.
- 매칭, 단계 이동, 점수·별·콤보, 소리 재생, 저장 규칙에는 변경을 넣지 않는다. 별도 애니메이션 패키지는 추가하지 않는다.

## 공통 아트와 나머지 미션

내장 `image_gen`으로 지도, 개울, 밤의 철길, 관측소, 안내 새, 열차 6장을 각각 생성했다. 전체 프롬프트와 최종 경로는 [생성 기록](learning-imagegen-prompts.json)에 있다. 생성 이미지를 웹용 WebP로 압축했으며, 새와 열차의 알파 투명도를 유지했다. 외부 레퍼런스의 이미지나 캐릭터를 복제하지 않았다.

- 탐험 지도는 생성된 풍경 위에 실제 HTML 미션 버튼을 배치한다. 작은 화면에서는 버튼을 별도의 세로 목록으로 정렬해 잘리거나 그림에 묻히지 않게 한다. 도감과 개별 미션은 동일한 새 캐릭터와 색을 사용한다.
- 다리 조각은 중력 가속도와 반발계수를 사용하는 낙하·재도약, 안내 새는 가속과 감속이 있는 포물선 점프를 사용한다. 모션은 음악 재생·정답 판정 시계와 분리하며, 화면 종료 시 프레임과 관찰자를 해제한다.
- 열차는 생성 이미지의 철길 위를 이동한다. 입력 순간 패드 눌림, 맞춘 박의 차체 반동, 연속 성공의 탄성 가속, 오답 피드백을 추가한다. 오디오 예약과 판정 허용 시간은 기존 규칙을 따른다.
- 메뉴와 도감 버튼의 클릭 반응은 감쇠 스프링으로 복원한다. 동작 줄이기 설정과 키보드 사용에서는 불필요한 튀는 동작을 생략한다.

음표·쉼표·악보 기호와 점수·진행 별은 정확한 의미를 전달하는 기능성 표기로 유지한다. 장식 풍경과 캐릭터는 생성 이미지로 표시한다. 제작 도구 및 이미지의 로컬 기본 저장 위치에 의존하는 경로는 앱에 포함하지 않는다.
