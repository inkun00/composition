# 파일당 1,000줄 제한

## 목적

한 파일이 화면, 상태, 오디오 처리, 데이터 변환 등 여러 책임을 동시에 갖지 않게 한다. 제한을 맞추기 위해 코드를 눌러 쓰는 것이 아니라 변경 이유가 같은 코드끼리 모듈로 나누는 것이 목적이다.

## 규칙

1. 사람이 작성하는 `.ts`, `.tsx`, `.js`, `.jsx`, `.mjs`, `.cjs`, `.css`, `.scss` 파일은 빈 줄과 주석을 포함한 물리적 1,000줄 이하여야 한다.
2. 800줄은 사전 경고선이다. 800줄 이상인 파일에는 새 기능을 바로 덧붙이지 않고 먼저 분리 경계를 정한다.
3. 새 파일은 예외 없이 1,000줄 제한을 적용한다.
4. `.generated.`가 들어간 자동 생성 파일은 직접 편집하지 않는 조건으로 제외한다.
5. 기존 초과 파일은 현재 크기를 동결 상한으로 둔다. 한 줄이라도 증가하면 검사가 실패하고, 1,000줄 아래로 내려오면 예외를 제거한다.

## 권장 분리 경계

- React: 화면 영역 컴포넌트, 상태·이벤트 훅, 순수 변환 함수
- 오디오: 재생 스케줄링, 노래 연습, 녹음, 오프라인 내보내기, 인코딩
- CSS: 화면 또는 컴포넌트 영역별 스타일
- 데이터: 원본 데이터와 생성 코드를 분리하고 결과 파일은 자동 생성 표시

## 현재 동결된 기술 부채

| 파일 | 동결 상한 | 다음 분리 방향 |
|---|---:|---|
| `src/App.tsx` | 3,131줄 | 작곡 편집기, 반주 설정, 녹음·연습, 저장·공유 화면 |
| `src/audio/player.ts` | 1,705줄 | 공통 오디오 그래프, 재생, 연습, 녹음, MP3 내보내기 |
| `src/styles.css` | 1,164줄 | 기본·편집기·반주·노래 모드 스타일 |

이 표는 영구 면제가 아니다. 각 파일이 1,000줄 이하가 되면 검사기의 레거시 상한에서도 삭제한다.
