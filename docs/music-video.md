# 그림으로 만드는 뮤직비디오

악보의 가사에 장면을 연결하고 음악·그림·가사를 MP4로 만든다. 장면 전체 또는 선·도형 개체별로 모션그래픽 효과를 고른다. 그림이나 가사를 자동 분석하지 않으며 모델 다운로드나 API 키가 필요 없다.

## 사용 순서

1. 악보에 가사를 넣고 빠르기와 반주를 정한다. 목소리를 넣으려면 현재 악보로 노래를 녹음한다.
2. **악보, 음악 저장 → 장면 그리기**에서 브러시·직선·사각형·타원·지우개로 그린다. **선택** 도구에서는 선·도형을 한 번 클릭해 개체 전체를 고른다. 마우스·터치·펜, 색·굵기·배경, 실행 취소·다시 실행을 지원한다.
3. **장면 시작 마디 / 마지막 마디**에서 구간을 고른다. 음절이 아닌 한 마디 단위로 선택하며, 가사가 없는 마디도 고를 수 있다. 전주에는 **전주 장면 추가**로 별도 그림을 넣거나 첫 장면의 구간에서 **전주**를 고른다. 전주는 본곡의 1마디 앞에 재생된다.
4. **이 장면은 어떻게 움직일까요?**에서 **등장 / 전환 / 이동 / 분위기** 중 종류를 고르고 효과 카드를 누른다. 노래의 BPM에 맞춰 재생 속도를 자동으로 조절한다. 바로 미리보기가 재생되고 같은 카드를 다시 누르면 처음부터 재생한다. 시간 막대를 움직여 원하는 시점을 확인할 수 있다.
5. 다음 장면을 추가하고 그림·움직임·끝 마디를 정한다. 마지막 장면은 노래의 마지막 마디까지 지정한다. 장면별 움직임은 서로 독립적이다.
6. 하단의 **음악·모션 미리보기**에서 재생을 누르면 음악·가사와 모든 장면의 움직임을 함께 확인한다. 일시정지·처음부터·시간 이동을 지원하며, 창을 닫으면 음악이 멈춘다. 휴대폰에서는 **미리보기**로 표시한다.
7. **뮤직비디오 만들기**에서 **애니메이션 있음/없음**을 고른다. 완료 영상은 팝업에서 확인하고 MP4로 저장한다. 진행률과 생성 취소를 지원한다.

그림판은 Procreate Dreams의 캔버스·장면 타임라인 구성과 DaVinci Resolve의 편집 패널 배치를 참고했다. 짙은 편집 화면 안에 밝은 도화지를 두고, 왼쪽 그리기 도구·위쪽 색과 굵기·오른쪽 장면 설정·아래쪽 장면 타임라인으로 나눈다. 선택한 장면이 타임라인에 보이도록 가로 스크롤을 맞춘다. 격자는 편집 화면에만 표시되며 PNG와 영상에는 들어가지 않는다. 휴대폰은 **그림판 보기 / 장면 설정 보기**로 전환한다.

타임라인에서 장면을 선택한 뒤 **앞에 삽입 / 뒤에 삽입**으로 중간에 빈 슬라이드를 넣는다. 인접 장면의 마디 구간을 나누고, 바로 옆에 여유 마디가 없으면 가까운 장면의 여유 마디를 배정한다. 마디가 부족하거나 기존 구간이 겹치고 비어 있어도 삽입할 수 있으며, 이때 기존 구간을 보존하고 선택한 장면의 마디에 새 장면을 임시로 연결한다. 기존 동작이 새 구간을 벗어나더라도 동작을 삭제하지 않고 문제 장면과 해결 방법을 표시한다. 구간 겹침·빈 마디·마지막 미연결·동작 범위 문제를 모두 해결하기 전에는 미리보기와 정적·애니메이션 MP4 생성을 막는다. **장면 삭제**는 삭제한 구간을 이웃 장면으로 이어 주며 마지막 본곡 장면은 하나 남긴다. 삽입·삭제는 실행 취소·다시 실행과 자동 저장을 지원한다. 전주는 맨 앞에 유지하며 전체 장면은 최대 24개이다.

마디가 다른 장면과 연결되어 있어도 시작·끝 마디를 선택할 수 있다. 구간을 수정하면 이웃 장면의 원래 시작·끝 마디를 보존하고, 겹친 마디와 해당 장면을 경고 패널·타임라인에 표시한다. **겹친 장면부터 뒤로 밀기**는 장면 길이를 유지하며 겹친 장면과 그 뒤 장면들을 이동한다. 노래 끝을 넘으면 변경하지 않고 부족한 마디 수를 안내한다. 이때 경고의 **장면 보기**로 해당 장면을 선택해 구간을 앞뒤로 조절하거나 불필요한 장면을 삭제한다. 고정된 마디에 연결된 이전 동작이 이동 범위를 벗어나면 움직임 재선택을 안내한다.

겹친 구간, 장면이 없는 빈 마디, 순서가 맞지 않는 구간이 남아 있으면 음악·모션 전체 미리보기와 MP4 생성을 막고 수정할 부분을 안내한다. 편집 중인 구간과 그림은 충돌이 있어도 브라우저·프로젝트 저장에 남으며, 구간 조정·밀기·삭제도 실행 취소로 되돌릴 수 있다.

**선택** 도구로 선·도형을 클릭하고 Shift로 여러 개를 고른 뒤 **복사 / 붙여넣기** 버튼 또는 **Ctrl+C / Ctrl+V**(Mac은 ⌘C / ⌘V)를 사용한다. 선택 모드의 **Ctrl+A**로 현재 그림 전체를 고를 수 있다. 복사한 개체는 다른 슬라이드에서도 붙여넣고, 원본 슬라이드를 지운 뒤에도 그림판을 열어 둔 동안 사용할 수 있다. 붙여넣은 그림은 약간 옆에 표시되며 색·굵기·필압·개체별 동작을 유지한다. 복제된 개체와 모션 그룹은 새 ID를 사용하므로 원본과 별도로 편집한다. 입력칸에서는 기존 텍스트 복사·붙여넣기를 유지한다.

휴대폰에서는 그림판 공간을 확보하도록 상단의 **장면 옵션** 버튼 안에 장면 저장·초기화·이전 그림 찾기를 둔다. 복사·붙여넣기는 항상 표시한다.

완성 영상은 별도 보기창에서 재생·다운로드한다. 창을 닫은 뒤에도 **완성 영상 보기**로 다시 열 수 있으며, 영상이 만들어져도 도화지 영역을 계속 확보한다. 편집 UI는 CSS·생성 이미지·사용자 그림 SVG로 구현했으며 참고 앱의 이미지나 자산을 포함하지 않는다.

그림 도구·저장·재생 등 조작부와 모션 효과 30종의 샘플은 [생성 이미지](studio-imagegen-v1/README.md)를 사용한다. 모션 카드는 효과에 맞는 종이 입체 장면을 보여주며, 그림·가사와 실제 모션은 기존 미리보기에서 확인한다.

현재 악보와 일치하는 녹음이 있으면 목소리와 반주를 사용하고, 없으면 악보의 가락과 반주를 렌더링한다. 전체 미리보기는 MP4를 인코딩하지 않고 음악을 준비한 뒤 재생한다. 영상 저장과 같은 음악·전주·장면 구간·가사 계획과 렌더러를 사용하며, 실제 오디오 재생 시각에 화면을 맞춘다. 장면 설정의 작은 미리보기에서는 해당 장면의 움직임만 빠르게 확인한다.

## 장면 모션그래픽

상단의 **전체 장면 자동 모션**을 누르면 현재 악보의 음높이·음표 길이·쉼표·붙임줄·BPM을 장면의 마디 구간별로 읽고 모든 그림에 효과를 한 번에 적용한다. 상행·하행 가락은 위·아래 이동, 촘촘한 리듬과 도약은 박자 움직임, 길게 이어지는 음은 부드러운 이동·확대, 쉼이 많은 구간은 여유 있는 등장 효과를 고른다. 비슷한 구간이 이어지면 같은 계열 안에서 움직임에 변화를 준다. 재생과 MP4는 기존 BPM 시계를 사용한다.

빈 장면은 그대로 두고, 장면의 끝 마디가 올바르게 정해진 경우에 실행한다. 가사 입력과 마디 완성을 마치기 전에도 현재 음표를 기준으로 적용할 수 있다. 자동 적용은 장면 전체의 효과로 기존 개체별 동작을 교체하며, 한 번의 실행 취소로 전부 복원한다. 이미 같은 추천이 적용된 상태에서는 실행 취소 기록을 추가하지 않는다.

장면 설정의 **음악에 맞춘 자동 모션**을 열면 현재 악보를 기준으로 장면별 추천 효과와 이유, 적용 상태를 확인할 수 있다. 가락을 바꾸면 추천이 갱신되며 다시 버튼을 눌러 적용할 수 있다. 적용한 효과는 기존 장면 카드에서 개별 변경할 수 있다.

| --- | --- |
| 움직임 없음 | 원본 그림을 그대로 표시 |

| 서서히 나타나기 | 장면 시작에 그림을 점차 선명하게 표시 |
| 옆에서 들어오기 | 왼쪽에서 제자리로 부드럽게 등장 |
| 천천히 확대 | 장면이 재생되는 동안 그림을 조금씩 확대 |

| 통통 뛰기 | 음악의 박자에 맞춘 도약 |
| 박자에 맞춰 팡팡 | 음악의 박자에 맞춘 확대·축소 |
| 팝업 등장 | 작은 그림이 톡 커진 뒤 원래 크기에 정착 |
| 원형 펼침 | 중심에서 원이 커지며 그림 전체를 공개 |
| 커튼 열기 | 중앙에서 양옆으로 열리며 그림을 공개 |

| 오른쪽으로 이동 | 장면이 재생되는 동안 오른쪽으로 이동 |

효과는 전체 그림 또는 선택한 개체에 적용한다. 총 30종이며, 개체마다 서로 다른 효과를 지정할 수 있다. 자동 사물 구분, 제어점 편집, 한국어 동작 추측은 사용하지 않는다. 원본 선 좌표와 필압은 보존한다. 배경과 가사는 움직이지 않는다.

## 선·도형 단위 선택

- **선택** 도구에서 개체를 클릭하면 한 번에 전체가 선택된다. 한 번 이어 그린 붓 선은 점의 개수와 상관없이 한 개체다. 사각형과 타원은 내부를 눌러도 선택되고, 겹친 곳은 위에 그린 개체를 고른다.
- 다른 개체를 클릭하면 선택을 옮기고 빈 곳을 클릭하면 선택을 해제한다. 선택만으로 그림을 추가하거나 실행 취소 기록을 만들지 않는다. 파란 선택 표시는 편집 화면에만 표시한다.
- **선택한 개체**에 효과를 적용하면 다른 개체에 이미 지정한 효과는 유지한다. 선택하지 않은 기본 개체는 고정된다. 선택을 해제해도 저장한 효과는 남는다. 해당 개체의 **움직임 없음**을 고르면 그 개체를 고정할 수 있다.
- **적용한 개체 동작** 목록은 현재 장면에 지정한 효과를 표시한다. 여러 개체를 함께 선택해 적용한 효과는 **그룹 · 개체 수**와 합쳐진 그림 미리보기로 한 줄에 표시한다. 그룹을 누르면 구성 개체가 함께 선택되고, 그룹의 **동작 삭제**를 한 번 누르면 구성 개체의 효과를 모두 지운다. 그림 원본과 다른 그룹의 효과는 유지하며, 한 번의 실행 취소로 그룹 전체를 복원한다.
- 따로 적용한 효과는 같은 동작이어도 별개의 그룹으로 남는다. 그룹 중 일부를 선택해 다시 적용하면 그 개체들만 새 그룹으로 분리된다. 그룹 기록이 없는 이전 그림은 같은 동작끼리 묶어 표시한다. 개별 효과는 도구 이름·그리기 순서로 표시하며, 여러 행을 선택한 뒤 **선택한 동작 삭제**로 함께 지울 수도 있다.
- **전체 그림**에 새 효과를 적용하면 기존 개체별 효과를 전체 효과 하나로 교체한다. 효과 적용은 실행 취소·다시 실행이 가능하다.
- 휴대폰에서는 개체를 선택한 후 **장면 설정 보기**에서 효과를 고른다. 선택 모드에서 아무 개체도 선택하지 않았을 때는 효과를 적용하지 않는다.
- 개체별 효과와 그룹 정보는 장면 JSON·작품 임시 저장·클라우드에 함께 보관한다. 미리보기와 MP4는 원래 그리기 순서를 유지하며 각 개체의 효과와 BPM을 사용한다. **애니메이션 없음**과 PNG 저장은 선택 표시와 모션 없이 원본 그림을 표시한다.

이 선택 기능은 선·도형 전체를 고른다. 한 획의 중간만 잘라 고르는 자유 영역 선택은 포함하지 않는다.

이동 효과는 장면의 처음부터 끝까지 선택한 방향으로 진행한다. 통통 이동은 가로 이동에 BPM에 맞춘 도약을 더한다. 선 굵기를 포함한 그림의 외곽과 도약 높이로 이동 여백을 계산한다. 붓의 외곽이 도화지 밖으로 나간 그림은 먼저 화면에 맞추고, 필요한 이동 여백을 확보하기 위해 최대 12% 더 축소한다. 재생 중에는 같은 크기를 유지한다. 저장한 원본 그림은 바뀌지 않고 **애니메이션 없음**에서는 원본 크기로 표시한다.

미리보기와 MP4는 같은 박자 시계와 렌더러를 사용한다. 등장·그리기는 장면 시작부터 진행하고, 통통 뛰기·확대 반복·별·눈 등 반복 효과는 음악 전체의 박자 위치를 따라간다. MP4에서는 실제 전주와 음원 시작 지연을 반영한 노래 시작 시각을 기준으로 하므로 장면이 바뀌어도 박자가 어긋나지 않는다. 별·색종이·눈은 장면·개체 ID와 재생 시점으로 위치를 계산하므로 시간 막대로 되돌아가도 같은 시점에는 같은 화면을 표시한다. 개체별 마스크와 장식은 해당 개체의 외곽 범위에 맞춰 적용한다. 끝 마디를 정하기 전에도 효과 선택과 임시 미리보기가 가능하며, 영상 생성에는 올바른 장면 구간이 필요하다.

## BPM에 맞춘 자동 속도

속도 조작 없이 현재 악보의 BPM을 사용한다. 예를 들어 120 BPM의 두 박자는 1초, 180 BPM의 두 박자는 약 0.67초다. BPM을 바꾸면 미리보기의 시간표도 다시 계산한다.

| 효과 | 시간 기준 |
| --- | --- |
| 서서히 나타나기·옆에서 들어오기·팝업·원형·커튼·조각 모으기 | 2박 동안 등장 |
| 회전 등장·카드 뒤집기·사선으로 나타나기 | 4박 동안 등장 |
| 한 획씩 그리기·색종이·스포트라이트 | 8박 동안 진행 |
| 통통 뛰기·팡팡·둥실둥실·별빛 | 음악의 박자 위치로 반복 위상 계산 |
| 눈 내리기 | 한 박자에 내려오는 거리를 일정하게 유지 |
| 좌우·상하·대각선·통통 이동·확대·멀어지기 | 선택한 마디 구간의 처음부터 끝까지 진행, 구간 길이는 BPM에 따라 자동 계산 |

짧은 장면에서는 등장·그리기·장식이 장면 끝 전에 완료되도록 시간을 줄인다. **움직임 없음**과 **애니메이션 없음**은 정적 원본을 유지한다.

## 장면·음악의 시간과 저장

- 시작할 때 이전 임시 저장·직전 백업·오류로 따로 보관한 원본·프로젝트 보관본에서 복구 가능한 그림을 찾는다. 시작 과정에서 백업이 교체되기 전에 원본을 별도 복구 보관함에 보존한다. 다른 악보 정보가 손상됐거나 JSON 뒷부분이 끊겨도, 완전한 장면 데이터가 남아 있으면 해당 장면만 검증해 제안한다.
- 현재 그림과 다른 복구 가능한 기록이 발견되면 **이전에 그린 그림을 찾았어요** 팝업에서 장면 미리보기·출처·저장 시각을 확인한다. 사용자가 복구를 선택해야 새 프로젝트 사본을 만들며, 현재 작업과 원본 기록은 유지한다. 악보 전체를 읽을 수 있으면 노래와 그림을 함께 복구하고, 그림만 남았으면 현재 곡의 별도 사본에 복구한다.
- 복구 팝업은 같은 브라우저에서 최초 한 번만 자동으로 표시한다. 표시 여부를 따로 저장하므로 닫기·나중에 하기·새로고침 이후나 다른 그림 기록을 발견했을 때도 다시 자동으로 열지 않는다. 원본 기록은 보관하며 **메뉴 → 사라진 그림 찾기**, **내 악보함 → 사라진 그림 찾아보기**, 그림판의 **이전 그림 찾기**에서 직접 다시 확인할 수 있다. 현재 표시 중인 그림이나 완성한 선에 이미 포함된 중간 기록은 자동 제안하지 않는다.
- 로그인한 계정의 열 수 없는 악보에 정상 그림이 남아 있으면 그림만 복구 후보로 제공한다. 계정이 바뀌면 이전 계정의 후보를 새 계정 기록으로 표시하지 않는다. 한 번도 저장되지 않은 선, 완전히 지워지거나 덮어쓴 기록, 온전한 데이터가 남지 않은 장면은 복구할 수 없다.

- 그림을 그리는 도중부터 선·도형·배경·장면 구간·개체별 모션을 브라우저에 자동 저장한다. 터치 취소, 포인터 캡처 해제, 도구·장면 전환, 팝업 닫기와 페이지 숨김 때도 그때까지의 선을 보존한다. 한 획은 실행 취소 한 번으로 되돌린다.
- 입력점은 손실 없이 모으고 그림판 표시는 화면 프레임마다 한 번 갱신한다. 작품 체크포인트는 그리는 동안 120ms 간격으로 합치고 획 종료·편집 명령·종료 이벤트에서는 마지막 점까지 즉시 반영한다. 화면을 떠나는 native 이벤트는 동기 체크포인트를 먼저 마치며, 변경하지 않은 장면 미리보기·fingerprint·같은 revision의 중복 저장을 재사용한다. 그리는 동안 모션 미리보기의 별도 렌더링은 잠시 멈춘다.
- localStorage의 최신 체크포인트와 직전 정상 복구본에 더해 IndexedDB에 프로젝트별 보관본을 저장한다. localStorage 용량이 부족하면 압축 또는 IndexedDB로 보관하며, 앱 시작 시 복원을 마친 뒤 자동 저장을 시작한다. 다른 곡이나 새 곡을 열어도 이전 그림은 **내 악보함 → 이 기기에 자동 보관한 그림**에서 다시 열 수 있다.
- 로그인한 계정에서는 그림을 처음 그리면 프로젝트에도 자동 저장하고, 이후의 그림·음악 수정도 같은 프로젝트에 이어 저장한다. 프로젝트 연결은 새로고침 후에도 유지한다. 인터넷 연결이 끊기면 브라우저 복구본을 유지하고 재접속 때 다시 시도한다. 큰 그림은 클라우드 저장 시 손실 없이 압축한다.
- 이전 프로젝트를 열 때는 같은 프로젝트의 최신 브라우저 보관본을 먼저 확인한다. 다른 기기의 더 최근 프로젝트를 덮을 위험이 있으면 로컬 작업을 별도 복구 사본에 보관한다. 브라우저와 프로젝트의 실제 저장 상태·실패 사유는 그림판 하단에 표시한다.

- 전주 그림은 실제 반주 또는 녹음의 전주가 끝날 때까지 재생한다. 전주 장면을 지정하지 않았거나 전주 그림이 비어 있으면 검은 배경에 흰색 곡 제목과 **작곡가**를 표시한다. 작곡가는 악보에 입력한 작곡가 이름을 사용한다. 제목·작곡가 화면에는 가사를 표시하지 않는다.
- 전주 장면은 맨 앞에 하나만 둘 수 있다. 전주를 추가·삭제해도 본곡 장면의 마디 구간은 유지한다. 전주에서 본곡으로 넘어갈 때 첫 본곡 장면을 처음부터 재생하며, 전주 설정은 장면 파일·작품 임시 저장·클라우드에 함께 보관한다. 그림을 초기화하면 전주 구간은 남고 제목·작곡가 화면을 사용한다.
- 음표의 실제 길이와 BPM으로 음악·가사의 시간을 계산한다. 쉼표·가사 없는 음표·전주·후주를 포함한다. 영상은 1280×720, 24fps다.
- 장면은 선택한 마디가 끝날 때까지 표시한다. 중복·역순·누락된 끝 마디와 마지막 마디 미포함을 검사한다. 옛 음표 ID 기준 구간도 불러오며, 구간을 수정하면 마디 단위로 저장한다.
- **애니메이션 없음**은 처음부터 완성된 원본 그림과 같은 음악·가사 시간표를 사용한다. 선택한 효과는 지우지 않는다.
- **장면 저장**은 그림·배경·선택한 효과를 담은 편집 가능한 JSON을 저장한다. 옆 메뉴에서 960×540 원본 PNG 저장과 장면 파일 불러오기를 사용할 수 있다. PNG에는 자막·움직임·격자를 넣지 않는다.
- **장면 초기화**는 현재 장면의 그림·배경·움직임을 빈 흰 도화지로 되돌린다. 장면 ID·마디 구간·다른 장면은 유지하고 실행 취소로 복원할 수 있다. 파일 불러오기도 현재 장면의 ID와 구간을 유지한다.
- 그림과 효과는 로컬 임시 저장·클라우드 악보함에 함께 보존한다. 클라우드는 중첩 배열을 피하도록 장면을 JSON 문자열로 저장하고 UTF-8 700,000바이트 제한을 적용한다. 완성 MP4는 다운로드한다.
- 이전 파일의 대상별 동작도 재생할 수 있다. 새 효과 카드를 고르면 해당 장면의 이전 동작을 교체하며 실행 취소로 복원할 수 있다.
- 프로젝트 최대 24장면, 장면당 240개 선·도형, 선당 1,200점, 전체 24,000점이다. 좌표·색·도구·참조·시간·용량을 검증한다. 기존 대상별 동작 데이터에는 장면당 12대상·48동작 제한을 유지한다.
- MP4 생성에는 브라우저 WebCodecs 인코더가 필요하다. 취소하거나 실패해도 편집한 장면은 유지한다.

## 검증

`node scripts/verify-scene-slide-editing.mjs`는 별도 브라우저 저장소에서 중간 슬라이드 삽입·삭제·되돌리기·마지막 마디 인계, 장면 사이 개체 복사·붙여넣기와 모션 그룹 독립성, 선택 표시·자동 저장·새로고침, 데스크톱·모바일 버튼 접근을 확인한다. `APP_URL`을 지정하면 운영 빌드의 JS/CSS 일치도 함께 확인한다.

`node scripts/verify-lost-drawing-recovery.mjs`는 독립된 브라우저에서 시작 전 백업 보존, 복구 여부 팝업·거절 기억·수동 재검색, 압축된 백업의 독립 사본 복구, 현재 프로젝트 보호, 동일 그림·중간 선의 중복 안내 억제, 손상 JSON의 온전한 장면 복구, 새 곡 이후 잘못된 재안내 방지를 검사한다. `APP_URL`을 지정하면 운영 사이트와 검사한 빌드의 일치도 함께 확인한다.

`node scripts/verify-scene-autosave.mjs`는 실제 Chrome의 독립된 테스트 저장소에서 펜을 떼기 전 저장, 취소·닫기·새로고침 후 복원, 그룹 모션 보존, 새 프로젝트와 기존 보관본 분리, localStorage 용량 초과 시 IndexedDB 복원을 확인한다. 단위 테스트는 계정 자동 저장·저장 중 편집·계정/프로젝트 전환·재접속·이전 저장 형식·압축 데이터 복원도 검사한다.

단위 테스트는 30개 효과의 저장·선택·실행 취소, 장면 간 독립성, 한 획씩 재생하는 순서·길이·필압, 서로 다른 BPM의 동일 박자 위치, 전주·음원 시작 지연과 장면 변경 후 박자 위상, 이동 방향·가장자리 안전성, 원본 보존 및 정적 출력을 확인한다. 이전 파일 호환과 마디 범위 검증도 유지한다.

`npm run build` 후 `node scripts/verify-scene-presets.mjs`는 실제 앱에서 그림 입력, 효과 30종의 미리보기 픽셀 변화와 이동 방향, 90·180 BPM의 같은 박자 화면, 빠르기 입력 변경, 장면 저장·불러오기·초기화·복원, 반응형 화면 및 정적·애니메이션 720p MP4를 확인한다. MP4에서는 실제 전주와 음원 시작 지연 이후의 정박·반 박자 도약도 검사한다. `APP_URL`로 배포 앱을 지정할 수 있다. 검증용 장면은 테스트 브라우저의 로컬 저장소에만 만든다.

`node scripts/verify-scene-files.mjs`는 JSON·PNG 저장, 초기화·실행 취소, 파일 불러오기, 잘못된 파일 오류 및 새로고침 후 복원을 확인한다. 결과는 `artifacts/`에 보관한다.

`node scripts/verify-assigned-motions.mjs`는 실제 앱에서 개체별 효과 목록·선택·개별/일괄 삭제·실행 취소·저장/복원과 240개 목록의 스크롤을 확인한다. 삭제한 개체가 고정되고 다른 개체의 움직임이 유지되는지 미리보기와 정적·애니메이션 MP4로 검사하며, `APP_URL`로 배포 앱을 지정할 수 있다.
