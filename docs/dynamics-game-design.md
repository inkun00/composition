# 셈여림 지휘자

확인일: 2026-11-07. 초등 4–6학년이 같은 가락의 셈여림을 직접 바꾸고 비교하는 네 미션의 지휘 시뮬레이션으로 설계한다. 기호와 뜻의 위치를 외우는 기억 게임을 현재 게임 메뉴에서 대체한다.

## 공식 자료와 설계 근거

- [Carnegie Hall — Explore Expressive Qualities in Music and Movement](https://www.carnegiehall.org/Education/Programs/Link-Up/National-Program/The-Orchestra-Moves/Explore-Expressive-Qualities-in-Music-and-Movement): 공식 수업 자료 본문에서 빠르기·셈여림·아티큘레이션을 서로 다른 표현 요소로 설명하며, 셈여림은 소리의 크기로 정의한다. `p`, `f`, 크레셴도와 데크레셴도를 소개하고, 학생이 익숙한 곡을 지휘하며 연주가 의도에 맞게 달라졌는지 살피는 활동을 제안한다. 이 앱에서는 기호 선택 → 같은 가락 연주 → 소리 변화 비교로 옮긴다. 구체적인 게임 구성은 우리 앱의 해석이다.
- [Texas A&M University Libraries — Steps to Music Theory, 2.9 Dynamics](https://odp.library.tamu.edu/stepstomusictheory/chapter/more-basics/): 공식 교재 본문을 직접 확인했다. 셈여림은 상대적인 크기이며, `p`와 `f`의 대비는 분명해야 한다고 설명한다. 크레셴도는 점차 커짐, 디미누엔도·데크레셴도는 점차 작아짐으로 구분한다. 이 앱에서는 절대 데시벨이나 기기 음량 백분율을 기호의 정의처럼 제시하지 않는다.

## 학습 동작

| 미션 개념 | 학습자가 조절하는 것 | 비교에서 유지할 것 |
| --- | --- | --- |
| `p` · 여리게 | 상대적으로 작은 소리 | 가락의 음높이·리듬·빠르기·악기 |
| `f` · 세게 | 같은 가락에서 더 큰 소리 | 가락의 음높이·리듬·빠르기·악기 |
| 크레셴도 · 점점 세게 | 시간에 따라 커지는 소리 | 음높이와 빠르기를 올리지 않음 |
| 데크레셴도 · 점점 여리게 | 시간에 따라 작아지는 소리 | 음높이와 빠르기를 내리지 않음 |

셈여림 기호는 음악의 상대적인 음량 표현이다. “더 세게”를 “더 높게” 또는 “더 빠르게”와 혼동하지 않도록 동일한 연주 조건에서 소리 크기의 변화만 비교한다. 기기 음량은 듣기 환경을 조절하는 별도 값이다. 감정과 셈여림의 관계에는 한 가지 정답을 강요하지 않는다.

별빛 음악회 배경은 기존 관측소 이미지를 활용한다. 학습 조작부는 실제 기호와 한글 뜻, 재생 상태를 분명히 보여 주며, 꾸밈 그림이 조절 가능한 UI를 대신하지 않는다.

## 기존 기록과의 관계

- 현재 게임 ID는 `bridge`, `train`, `dynamics`이다. 메뉴는 “셈여림 지휘자 / 03 · 별빛 음악회 / 4개 미션”으로 표시한다.
- 기존 `maeum-melody:games:v1` 저장 키와 다리·열차의 최고 별·최고 점수 규칙은 유지한다.
- 이전 `memory` 기록은 읽기·병합·저장 과정에서 보존하는 레거시 데이터다. 현재 별·점수 합계 및 새 게임 완료 여부에는 포함하지 않으며, 새로운 기억 게임 결과를 기록하는 입력도 받지 않는다.
- 기존 기억 게임 컴포넌트와 모델은 삭제하지 않는다. 기존 기록을 새 셈여림 게임의 성적으로 변환하지 않는다.
