마음멜로디 실행 안내

ZIP을 원하는 폴더에 모두 압축 해제한 뒤 실행해 주세요. 인터넷 연결이 필요합니다.

HTML 파일로 바로 실행

index.html 열기를 누르거나 폴더에서 해당 파일을 더블클릭하세요. Edge 또는 Chrome 최신 버전을 권장합니다. 개발 도구 설치는 필요하지 않습니다.

작곡 화면, 이미지, 효과음, 비트 음원은 패키지에 포함되어 있습니다. 악기 음원과 글꼴은 인터넷에서 불러옵니다. 이메일 로그인과 악보함은 기존 Firebase에 연결됩니다.

HTML을 직접 열면 Google 로그인은 브라우저의 주소 제한으로 사용할 수 없습니다. Google 계정은 아래 전체 기능 실행을 이용하세요.

Windows에서 전체 기능 실행

  1. 압축을 푼 폴더의 전체기능-실행.cmd를 더블클릭합니다.
  2. 브라우저가 자동으로 열리면 앱을 사용합니다. Google 로그인도 이 화면에서 이용합니다.
  3. 앱을 다 사용한 뒤 실행 창에서 Enter를 눌러 종료합니다.

Windows에 기본 포함된 PowerShell로 이 폴더를 컴퓨터 내부에서 제공합니다. Node.js 설치는 필요하지 않습니다. 실행 창을 종료하면 서버도 종료됩니다.

브라우저 주소는 http://localhost:4173이며, 포트가 사용 중이면 가까운 빈 포트를 사용합니다. 로그인 팝업이 차단되면 브라우저에서 허용해 주세요.

악보 사진을 읽으려면

전체 기능 실행으로 앱을 연 뒤, 같은 폴더의 start-score-reader.cmd를 실행하세요. 기존 앱과 동일하게 사진 인식 도우미에는 Node.js와 Python 실행환경이 필요합니다. 최초 모델 준비에는 다운로드 시간이 걸립니다.

사진을 사용하지 않는 MusicXML·MXL 악보 파일 가져오기는 별도 도우미 없이 사용할 수 있습니다.

저장과 공유

이메일·Google 로그인과 클라우드 악보는 기존 데이터베이스를 그대로 사용합니다. 로컬 브라우저 저장과 로그인 상태는 컴퓨터·브라우저·실행 주소마다 다릅니다. 다른 컴퓨터로 옮길 작업은 악보함에 저장해 주세요.

공유 링크·스마트폰 녹음·PDF의 QR은 기존 온라인 앱 주소를 사용합니다. 수신 기기에는 압축 파일이 없어도 되며, 온라인 앱의 운영이 필요합니다.

폴더 이름과 위치를 바꿔도 실행할 수 있습니다. index.html과 assets 폴더를 함께 유지해 주세요. ZIP 안에서 파일을 직접 열지 마세요.
