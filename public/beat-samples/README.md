# 실제 비트 악기 샘플

이 폴더는 비트 악기 미리듣기와 반주 재생에 쓰는 실제 악기 원샷 샘플을 담습니다.
모든 원본은 CC0 또는 Public Domain으로 공개되어 상업·비상업 용도로 사용할 수 있습니다.

## 밴드 드럼

`kick.wav`, `soft-kick.wav`, `snare.wav`, `hihat.wav`, `rack-tom.wav`,
`open-hihat.wav`, `crash.wav`는
Sample Pi의 Public Domain 어쿠스틱 드럼 샘플을
44.1kHz, 16비트 PCM WAV로 변환한 파일입니다.

- `kick.wav`: Menegass의 `drum_bass_hard` — 낮고 묵직한 어쿠스틱 베이스 드럼
- `soft-kick.wav`: Menegass의 `drum_bass_soft` — 둥글고 부드러운 어쿠스틱 베이스 드럼
- `snare.wav`: Menegass의 `drum_snare_hard` — 타격음과 철망 울림이 선명한 어쿠스틱 스네어
- `hihat.wav`: Menegass의 `drum_cymbal_closed` — 짧고 선명한 어쿠스틱 하이햇
- `rack-tom.wav`: Menegass의 `drum_tom_hi_hard` — 단단한 어쿠스틱 높은 톰
- `open-hihat.wav`: Menegass의 `drum_cymbal_open` — 길게 열리는 어쿠스틱 하이햇
- `crash.wav`: Menegass의 `drum_cymbal_hard` — 강하게 퍼지는 어쿠스틱 크래시 심벌
- Sample Pi: https://github.com/alex-esc/sample-pi
